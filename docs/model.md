# The model

What is modelled, with which equations, and where every parameter comes from.

## Source families

Parameter values are anchored to these families. No page numbers or table numbers are
cited (the brief forbids fabricating them); where a value is not confidently canonical
it is marked **estimate** in its data file and here.

- **Power system analysis texts** — Glover, Overbye & Sarma, *Power System Analysis
  and Design*; Grainger & Stevenson, *Power System Analysis*. (Per-unit, Ybus,
  Newton–Raphson, symmetrical components, fault analysis, line constants.)
- **Distribution** — Kersting, *Distribution System Modeling and Analysis*. (Carson's
  equations, Kron reduction, backward/forward sweep, regulators, the IEEE 13-node feeder.)
- **Stability** — Kundur, *Power System Stability and Control*. (Swing equation,
  inertia constants, governor droop, equal-area criterion, machine parameters.)
- **Protection** — Blackburn & Domin, *Protective Relaying: Principles and Applications*.
- **Standards** — ANSI C84.1 (service voltage ranges), IEEE C37.2 (device function
  numbers), IEEE C37.112 (inverse-time characteristic equations), IEEE 738 (conductor
  ampacity), IEEE 80 (substation grounding), IEEE 1366 (reliability indices),
  IEEE C57.12.00 (transformer terminal markings and vector groups).
